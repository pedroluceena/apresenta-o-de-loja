# Apresentação de loja · Aquarela Moda Infantil

Prévia criada pela DigitalWorks com duas opções de site para a Aquarela (@aquarelakids2019), no mesmo visual de aquarela:

| Pasta | Opção | O que mostra |
|---|---|---|
| `loja-shopify/` | **Loja online (Shopify)** | Sacola, checkout com Pix, cartão e boleto, retirada na loja, conta do cliente, uma página por coleção com filtros |
| `loja-vitrine/` | **Site vitrine** | Catálogo sem carrinho: a cliente monta a lista e envia pelo WhatsApp, com botões para a Shopee e o Mercado Livre |

`index.html` é a página inicial, que deixa escolher entre as duas.

## Como abrir

- **Online:** GitHub Pages, em Settings → Pages → Branch `main` / pasta `/ (root)`. O endereço fica `https://pedroluceena.github.io/apresenta-o-de-loja/`.
- **Sem internet:** baixe o repositório e dê dois cliques em `index.html`. As fotos e as fontes estão dentro das pastas.

## Avisos

- **É uma demonstração:** nenhum pedido, pagamento ou e-mail é real, e o checkout não tem campos de número de cartão.
- **As fotos são de exemplo** (banco de imagens Unsplash) e vão ser trocadas pelas peças reais da loja.
- **Fora dos buscadores:** as páginas têm `noindex` e o site tem `robots.txt`, para não aparecerem no Google.
